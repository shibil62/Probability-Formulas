# Probability Formula Sheet · KTU

An interactive, single-file web reference covering Modules 1–4 of the KTU Probability syllabus. Built with zero external build steps, clean dark-mode typography, and expandable cards featuring symbol breakdowns, worked examples, and exam tips.

## Features

* **Interactive Formula Cards:** Tap `+` on any formula card to expand plain-English symbol definitions, an example problem, a step-by-step solution, and quick exam tips.
* **Sticky Module Navigation:** Jump smoothly across Modules 1 to 4 with scroll-spy highlighting.
* **Crisp LaTeX Rendering:** Powered by MathJax 3 (SVG output) for sharp mathematical equations on both desktop and mobile screens.
* **Single-File Architecture:** All markup, styles, custom DSL parser, and syllabus data live inside `probability-formulas.html`—no bundler, framework, or server required.
* **Mobile-Ready Dark UI:** High-contrast dark theme with safe-area inset support and horizontal scroll handling for wide equations.

## Syllabus Coverage

| Module | Topic | Key Concepts Included |
| :--- | :--- | :--- |
| **Module 1** | **Discrete Distributions** | PMF, CDF, Expectation, Variance & Properties, Binomial Distribution, Poisson Distribution, Joint & Marginal PMFs, Independence |
| **Module 2** | **Continuous Distributions** | PDF, CDF, Mean, Variance & S.D., Uniform Distribution $U(\alpha,\beta)$, Normal Distribution $N(\mu,\sigma)$ & Z-scores, Joint & Marginal PDFs |
| **Module 3** | **Limit Theorems & Stochastic Processes** | Markov’s Inequality, Chebyshev’s Inequality, Strong Law of Large Numbers, Central Limit Theorem, Counting & Poisson Processes, Interarrival Times |
| **Module 4** | **Markov Chains** | Markov Property, Transition Probability Matrix (TPM), Chapman–Kolmogorov Equations, Stationary Distribution ($\pi = \pi P$), State Classification, Periodicity |
